# 0. 实验简述

本实验构造用于后续结构动力学代理与系统辨识的完整状态自由衰减数据。研究对象是固支加筋 NACA 翼盒壳体与六个被动广义贴片连接件；连接件引入三次弹性势和平滑速度相关阻尼。静止支承是模型的一部分，因此该对象的物理身份不同于未增加连接件的原始机翼。目标是完成固定初态清单中的144条干净轨线，并逐条通过既定运行质量门槛和保存数据完整性检查。

实际流程为固定模型与人口配方、初态构造、完整物理坐标 Radau IIA5 积分、运行门槛检查、保存状态回读、不可变父文件复用以及最终外部完整性审计。输出包含全部29,844个状态分量，每条4096帧，时间间隔0.0005 s。模态只用于规定初态，动力学未截断到低维模态。探索性单轨线和四个展示样例独立保留，不增加正式人口数量。未运行学习模型、训练、模型选择或预测 Test 评分。

最终 `r4` 发布包含144个不同初态，Train/Validation/Test 为96/24/24，12个族均为8/2/2。全部文件通过原运行门槛、完整状态与端口回读及 SHA256 核验，最终无缺失或隔离成员。全体最大相对能量收支缺陷为 9.761689157e-05，最大恢复应变分量为 0.0006969655976，终点能量比例最大值为 0.2975764671。这支持本次固定模型、人口与门槛下的数据验收；用户豁免了独立时间、空间和采样资格验证，故正式标签始终为 `user_waived_independent_qualification`，不能将验收改称为完整数值认证。

# 1. 主要结果

主指标为 **144/144，100%**，其分母是冻结清单中的全部成员；不含试验轨线，也不含历史部分文件。最终外部审计重新读取全部保存状态、端口位移和速度，核验初始速度为零、原始初态哈希、4096帧时间网格、耗散分解、运行回执及每份 HDF5 的文件哈希。133个父文件仍与父发布保持不可变硬链接，11条为恢复后的新增静态释放；二者在完成回读之前没有混为同一计数。

验收诊断定义为
$$
\delta_E=\max_m\frac{\lvert\mathcal E_m+D_{0,m}+D_{c,m}-\mathcal E_0\rvert}{\mathcal E_0},\qquad
r_T=\frac{\mathcal E(T)}{\mathcal E(0)}.
$$
既定门槛为 $\delta_E\le10^{-4}$、恢复应变分量最大值不超过 $10^{-3}$、$r_T\le0.4$，并保留 Newton 缩放残差 $10^{-13}$、全状态有限性及完整回读要求。总体、逐族、逐轨线数值和原始精度位于[数值附录](NLC6_numerical_appendix.md#2-全体结果与运行门槛)。这些指标是运行验收诊断，不是独立参考解误差。

# 2. 初始化

壳体沿用固定上游网格与有限元实现，翼根约束消元后有14,922个机械自由度。质量采用单元局部集总质量经坐标变换装配的常质量矩阵，不是经独立一致质量认证的替代实现。六个无质量连接件共用固定稀疏映射 $\mathbf s=\mathbf B^\top\mathbf q$、$\mathbf w=\mathbf B^\top\mathbf v$，不增加状态。Rayleigh 阻尼按原参考刚度构造，第一、第四模态阻尼目标分别为1.0%和0.12%；全部轨线共享冻结物理参数。

初始速度统一为零。前四个单模态族、六个双模态族和一个四模态混合族通过质量归一化参考模态构造完整位移；第12族联合求解非线性静态力平衡和连接件能量比例约束，再移除预载。强度定义为连接件四次势能除以参考二次应变能，名义低／中／高层配额为24/60/60。五个第3族高层失败成员使用授权的0.8位移比例及0.64能量比例，仍保留原名义层索引；实际强度必须按逐条元数据解释。

静态初始化最初的延续在第二阶段接近零位移根，不能满足指定非零能量比例。`r3` 改为用 $\sqrt{R_{\mathrm{new}}/R_{\mathrm{previous}}}$ 预测非零分支，再求解相同非线性平衡与能量约束。力、修正量、比例和应变容差均未放宽。12个规定静态初态通过检查，最终12条对应动态轨线均验收；[附录](NLC6_numerical_appendix.md#4-静态初始化修复与暂停恢复)给出失败诊断与最终数值。

# 3. 主求解

实际积分采用三阶段五阶 Radau IIA，以 Float64 GPU 计算壳体几何内力，CPU 稀疏求解及秩18连接件阶段切线更新完成全状态隐式步。常规每个输出间隔内部2步，起始0.05 s使用32倍细分；五个已记录能量失败成员改用内部4步，其余容差、起始细分、物理参数、幅值及输出网格不变。数学笔记 §3.7 的2步描述对应基线设置，五例4步以冻结配置和修复记录为实际执行绑定。

## 3.1 偏差、修复及证据边界

最初第3族五例在动态应变门槛失败。原始初态与部分文件保留，版本化降低这五例幅值后全部通过4096帧验收；这改变了相应初态强度，不改变材料或连接件物理参数。原配方与替换后的幅值、强度和应变并列在[附录](NLC6_numerical_appendix.md#3-物理幅值调整与数值能量修复)。

另五例在应变仍合格时，能量收支缺陷略超过 $10^{-4}$。对此采用积分细化而非幅值调整，替换初态逐字节 SHA256 均与原始失败例一致。相同失败帧的缺陷缩小约29.6–29.8倍，完整替换轨线最大缺陷均通过原门槛。这是同初态的运行收支改善；缺少独立参考解与时间／网格资格实验，不能据此声称全状态误差获得同倍改善。

`r1` 在第77个计划成员第89帧后消失，未捕获 Julia 异常，原因仍未确定；脱离 Codex 终端的 WMI 隐藏监督是工程恢复措施，不是已证实的故障因果结论。`r2` 在第133个计划成员静态初始化处以 Julia 异常退出，127条已验收。`r3` 完成五例能量替换及首条静态释放轨线后，用户主动暂停，退出码130；原 `NLC6_test_023` 部分文件和过期锁保留。显式恢复建立 `r4`，从原初态重算中断成员，且其初态哈希与静态轨迹记录一致。`r4` 于2026-10-14 19:00:25 UTC以退出码0完成。

本次是数据生成质量控制，Validation/Test 名称表示后续学习划分。工程修复确实覆盖这些划分中的已失败初态；没有基于学习器 Test 预测评分选择模型。学习者应继承实际初态和数值设置的非均匀绑定，不能把此数据资源描述为各成员采用完全相同内部步数。

# 4. 冻结构建与后处理

接受后的 HDF5 不被重写。版本间复用通过哈希一致的不可变硬链接和来源回执完成，活动版本重新进行完整保存状态回读。最终发布清单只包含144个合格唯一成员，所有历史失败、暂停部分文件及父版本保留在各自原位置。最终外部审计绑定根清单、模型、20项冻结输入及源副本，并重新检查全部状态和端口。

此前组织的 GIF、诊断图和线性切向参考展示仍是说明材料。当前动画以10倍位移、6秒播放显示前0.20 s，数值历史使用完整4096帧。四个例子和独立试验不代表全人口非线性强度；线性响应相对差异混合了相位累积和积分误差，不能解释为“非线性百分比”。[唯一汇总页](tables/index.html)关联正式报告及附录，未重新生成或移动仿真数据。

# 5. 最终冻结评价

最终对象是 `dataset21_nlc6_f4096_144_v1_r4` 的完整人口及来源绑定，父链为 `v1 → r1 → r2 → r3 → r4`。全体96条Train、24条Validation、24条Test均通过相同运行门槛；最终 Test 成员的检查也是数据完整性和物理运行验收，预测泛化评分为 `N.A.`。逐族及逐成员结果详见[数值附录](NLC6_numerical_appendix.md#6-144条完整数值记录)。

本实验未完成独立时间细化误差认证、空间网格收敛、独立采样频带认证或消融。配置中的候选频带与时间细化目标是输入设计值，不是已测资格结果。完整状态没有降低物理自由度，但固定网格也不能代表连续体收敛；初态集中在规定低阶模态和静态释放，不覆盖任意初速、相位、加载或物理参数分布。此次可复用结论限定为所记录固定模型、初态人口与运行门槛下的干净自由衰减数据。
